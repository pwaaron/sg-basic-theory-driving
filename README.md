# Basic Theory of Driving — my study copy

My personal, unofficial reading copy of the Singapore **Basic Theory of Driving** handbook, plus a companion visual study guide.

- **[Open my handbook copy](https://pwaaron.github.io/sg-basic-theory-driving/handbook.html)**
- **[Open my study guide](https://pwaaron.github.io/sg-basic-theory-driving/road-sense.html)**

## What this is

I rebuilt my copy of the handbook page by page as real HTML, CSS and inline SVG — not page screenshots. All 89 printed pages are present, together with the cover, page runners, numbered rules, tables, road markings and sign grids. The original illustrations and road signs were traced into vector artwork so they remain sharp at any size.

The companion study guide reorganises the same material for revision: high-frequency rules, visual verdicts, decision flows, and the numbers that are easy to mix up.

## Notes

- Single-file editions: fonts, styles and artwork are embedded, so each HTML file works offline and can be opened directly from disk.
- The 2026 drink-driving amendment is shown as **passed but not yet in force**, alongside the limits currently in force.
- This is a personal, non-commercial study project. **It is not affiliated with, endorsed by, or published by the Singapore Traffic Police.** Original handbook content © Singapore Traffic Police. Check the current official handbook and Traffic Police notices before your test.

## Deployment

The site is published from the `main` branch root with GitHub Pages. `.nojekyll` is included so the files are served as-is.
